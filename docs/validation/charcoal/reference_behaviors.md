# Charcoal reference behaviors

These observations define the dry/brittle extreme the shared vocabulary must survive.

| Behavior | Expected observation | Canonical causes |
| --- | --- | --- |
| Catching tooth | Particles catch on raised texture and connected surface irregularity. | `SUBI-001`, `SUBI-002`, `TRIB-001`, `DEPO-001` |
| Valley skipping | A light mark deposits primarily on high points; increasing pressure progressively reaches valleys. | `SUBI-001`, `DEPO-001`, `DEPO-004`, `RHEO-004` |
| Brittle fracture | A solid source breaks into particle populations under loading. | `TRIB-003`, `PART-001`, `PART-003` |
| Dusting | Fine detached particles settle separately from larger mark fragments. | `PART-001`, `PART-002`, `DEPO-002`, `DEPO-003` |
| Smudging | Sliding contact relocates deposited particles through friction and pressure. | `TRIB-002`, `TRAN-004`, `DEPO-001` |
| Loose granular first layer | Particle capture is spatially incomplete; paper remains visible inside a one-layer mark. | `PART-002`, `PART-003`, `SUBI-001`, `DEPO-001` |
| Layer buildup | Repeated passes accumulate deposited mass and darken while preserving granular structure. | `DEPO-001`, `DEPO-004`, `PART-002`, `OPT` |
| Lifting | A later contact can remove or redistribute an earlier mark according to adhesion and cohesion. | `REAC-003`, `REAC-004`, `DEPO-003`, `SUBI-004` |
| Burnishing | Repeated pressure changes packing and appearance, eventually affecting how much more material can catch. | `RHEO-004`, `DEPO-004`, `TRIB-002`, `OPT-004` |
| Believable failure | Dusting, broken deposition, over-burnished rejection, and uneven skips arise from contact history. | `TRIB`, `DEPO`, `SUBI`, `OPT` |

The charcoal case passes structurally without a `charcoalMode`; it still requires careful calibration and artist review.
