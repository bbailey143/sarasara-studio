# Reference library

This folder receives deliberately selected reference material from the archived Sarasara project and from external research. Start with [`REFERENCE_CATALOG.md`](REFERENCE_CATALOG.md), which records what each source means and what it does not mean.

Suggested destinations:

- `research/`
- `legacy-architecture/`
- `legacy-brush/`
- `legacy-ui/`
- `material-studies/`
- `optical-studies/`
- `substrate-studies/`
- `testing/`

Reference material is evidence, not a direct implementation mandate. Each migrated item should retain its source and be classified before it influences the canonical vocabulary. The archive remains the recovery source; these extracts are the readable vNext interpretation.
